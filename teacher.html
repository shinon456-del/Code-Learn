Learning problem · #2

Chosen problem: #2 – Students lack hands-on opportunities in an ICT lesson.

ICT context: Basic HTML and web development.

Problem statement: ICT learners have limited opportunities to practice writing and applying basic HTML during traditional instruction, making it difficult for them to turn what they learn into a working webpage.

How CodeLearn responds: Learners use short lessons, a live HTML editor, code missions, automatic checks, assessment, and feedback to get repeated hands-on practice.

Target learners: First-year BTLED-ICT students with little or no prior web development experience.

Evidence: Replace with your class data (pre-test scores, teacher observation, interview notes). The pre-test and post-test in this site give you that evidence.

Desired improvement: Learners should become more able to actively apply basic HTML by completing the interactive missions and demonstrating improved assessment performance. Use the actual class results to report the final percentage.

TPACK analysis

Content (CK): HTML document structure, headings, paragraphs, links, images, buttons.

Pedagogy (PK): learning by doing with immediate feedback; short missions that build in difficulty.

Technology (TK): a browser-based editor with live preview and an automatic checker. It fits because HTML is a visual skill, and learners need to see the result of each change right away.

Curriculum change and force field analysis

Classification: Alteration. The same HTML topic and outcomes are kept. The change is a minor one in how the topic is practiced: hands-on, auto-checked missions replace worksheet-only practice. Revise this after your demo if your evidence says otherwise.

Strategies to reduce the restraining forces: If there are not enough devices, learners work in pairs, one typing and one reading, and switch after each mission. If the internet is poor, copy the CodeLearn folder to the computers or a flash drive, since the site works offline. For different skill levels, the missions go from easy to harder and the checker gives hints, so stronger learners can help their partners. For short class time, each mission takes about five minutes and can be done in a later session.
