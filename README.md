# CodeLearn v7

Open `index.html` in any browser. No install and no internet needed.

Pages: index (home), pretest, lessons, lab (code lab), assessment, teacher (curriculum documentation).
Progress, code, feedback and the improvement plan are saved in the browser and shared across pages.
Before presenting, edit the evidence and the improvement plan on the teacher page.

Pre-test: each learner takes it once before the lessons. The assessment and teacher pages then show pre-test vs post-test scores per outcome. Data is saved per device; use "Download class data" on the teacher page to collect each device's results.

Sending data to your Google Sheet: follow SHEET-SETUP.md (about 5 minutes). Results land in one row per learner. If a learner is offline, results wait on the device and send automatically once the internet is back.


Changes in v10: Code Quest now has an SVG knight hero (grows with level) and four unique animated monsters (Title Goblin, Link Phantom, Media Beast, Web Guardian) with attack, hurt, taunt and defeat animations.

Changes in v4: each lesson has a try-it practice editor; lesson quick checks have 3 options; Lesson 2 has a think-pair-share prompt; assessment and pre-test Q5 now measure Outcome 3 (why plan structure first).

Changes in v5 (testing and resetting):
- The site starts clean: it uses a new save slot, so test answers from older versions are ignored.
- Class log: every learner's pre-test and post-test is kept on the device (teacher page > "Class log on this device"), even after progress is reset.
- "Done. Next learner" button appears after the pre-test and after the assessment. It clears the current learner so the next person starts fresh. Scores stay in the class log.
- Post-test on a reset or shared device asks for the learner's full name and finds their pre-test by name (not case-sensitive). Use the same name both times.
- Teacher page: "Reset for next learner" (keeps the class log), "Download class log (CSV)", and "Erase everything" (wipes the log too, asks first).

Before the real class: test as yourself, then press Erase everything on the teacher page so no test scores are left in the log.
